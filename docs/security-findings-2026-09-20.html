Export: September 19, 2026, 9:45 PM Pacific. Reviewed against develop e2608ea. This report covers all 24 exported findings and the code changes on fix/codex-security-findings.

Remaining Verification

Historical MongoDB credential rotation and legacy alias data/index state remain unverified. Hit counts intentionally include every admitted redirect. Rate limits are per process; ingress-wide protection needs deployment evidence. Legacy infrastructure changes have not been applied. No cloud findings have been closed.

Patch Boundaries

Shared redirect resolution enforces the request budget and canonical origin for both public routes. Logging fixes cover redirects, CRUD operations, connection failures and span errors. Workflow changes remove shell interpolation and broad secret exposure, pin Actions, and narrow dependency auto-merge. Docker installs use the project npm policy and lockfile. Anti-framing headers protect the dashboard while confirmation protects deletion.
